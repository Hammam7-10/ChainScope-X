2. IMPLEMENTED TOOLS
All six tools perform deterministic operations against controlled synthetic resources:
- Document Reader: reads a registered asset or selected fields.
- Database Search: filters synthetic rows using the caller's query and limit.
- Data Transformer / Report Generator: creates a report object/file with source lineage and highest-input classification.
- File Creator: validates a name and creates a controlled file resource.
- Workspace Storage: stores files in the simulated internal workspace.
- File Sharing / Controlled Output: routes files only to fixed simulated internal/external destinations.

3. REGISTRY AND EXECUTION
A static allowlist accepts exactly the six approved implementation classes. It rejects duplicate/unknown tools, invalid manifests and unsupported schema definitions; validates inputs and output shapes; and exposes stable implementation references. The runner separates executions, invocations and effects, assigns unique IDs, and uses ordered, timezone-aware event sequences.

4. INSTRUMENTATION AND EVIDENCE
All resource adapters share the effect recorder. Events retain R1 effect enums, identity, operation, source/destination, classification, outcome and resolving evidence. Canonical sanitized event facts receive local SHA-256 digests. Recorder or evidence-store failure fails closed; staged writes/deliveries roll back and coverage is FAILED. Raw content, query text, filenames and untrusted resource/tool identifiers are excluded or normalized before entering evidence.
