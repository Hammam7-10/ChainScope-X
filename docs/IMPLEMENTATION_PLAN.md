# خطة التنفيذ المرحلية

تتطلب كل مرحلة تفويضًا صريحًا من مدير المشروع. لا يعني نجاح مرحلة السماح ببدء التالية.

| المرحلة | النطاق | حالة القبول |
|---|---|---|
| R0 | تدقيق البيئة والأساس المحلي القابل للاستعادة | مقبولة؛ محفوظة |
| R1 | المعمارية وعقود البيانات والسياسات والتغطية | مقبولة؛ محفوظة |
| R2 | مختبر الأدوات الاصطناعي الستة وتسجيل الآثار والأدلة والنسب | مقبولة؛ محفوظة |
| R3 | محرك موحد لمقارنة الآثار والرسم والمسارات والسياسات والنتائج | منفذة؛ 25 اختبار R3 و64 اختبارًا كليًا ناجحًا؛ بانتظار مراجعة المدير |
| R4 وما بعدها | أي تكامل أو توسع لاحق | غير مصرح بها؛ لا تبدأ دون تفويض منفصل |
| T1–T3 | تدقيق الجهاز اللوحي والنقل والتشغيل | معلقة حتى يتاح الجهاز المستهدف |

## نقطة التوقف بعد R3

R3 دمجت المقارنة الحتمية بين manifest والأثر، وبناء رسم القدرات من أحداث R2 الفعلية، وتقييم قواعد R1 المنظمة، وإنشاء النتائج ذات المراجع القابلة للحل. التنفيذ محلي وعابر للعملية؛ لم تضف قاعدة بيانات أو API إنتاجية أو LLM أو RAG أو علاجًا آليًا.

قدّم ملف `MANAGER_HANDOFF_R3.txt` الواحد للمراجعة ثم توقف. لا تبدأ R4 أو أي مرحلة لاحقة قبل موافقة مدير المشروع صراحة.
