# خطة التنفيذ المرحلية

تتطلب كل مرحلة تفويضًا صريحًا من مدير المشروع. لا يعني نجاح مرحلة السماح ببدء التالية.

| المرحلة | النطاق | الحالة |
|---|---|---|
| R0 | تدقيق البيئة والأساس المحلي القابل للاستعادة | مقبولة؛ محفوظة |
| R1 | المعمارية وعقود البيانات والسياسات والتغطية | مقبولة؛ محفوظة |
| R2 | مختبر الأدوات الاصطناعي الستة وتسجيل الآثار والأدلة والنسب | مقبولة؛ محفوظة |
| R3 | محرك موحد لمقارنة الآثار والرسم والمسارات والسياسات والنتائج | مقبولة ومحفوظة؛ 25 اختبار R3 أصلية |
| R4 | RAG محلي، تخطيط محدود، تكامل LangGraph مع R2/R3، وتقارير ذات مصادر | مقبولة ومحفوظة؛ 88 اختبارًا كليًا ناجحًا |
| R5 | تخزين PostgreSQL/Mongo وAPI محلية؛ UI مؤجلة | مفوضة ومنفذة على `r5-backend-persistence`؛ بانتظار مراجعة المدير |
| T1–T3 | تدقيق الجهاز اللوحي، النقل والتشغيل على Samsung Galaxy Tab S7+ / Debian PRoot | معلقة حتى يتاح الجهاز المستهدف |

## موجز بوابة R4

اكتمل R4 بإضافة استرجاع محلي عبر ChromaDB وFastEmbed/ONNX، وسياسات ثنائية اللغة ذات metadata/version/access filters، وخط LangGraph واحد من التحقق من الطلب إلى تقرير evidence/citations. الوضع الافتراضي mock حتمي؛ وضع Groq اختياري لتوليد اقتراح خطة فقط، ولم يتم التحقق من تكامل حي لغياب credential. تُراجع كل خطة حتميًا قبل وصولها إلى مختبر R2، ومحرك R3 هو السلطة الوحيدة للحكم الأمني.

شملت الأدلة تشغيل A–D، اختبارات تحديد الخطة/السياق واستعادة Chroma وRAG بالعربية والإنجليزية، واختبار regression كامل (**88 passed** مع `HF_HUB_OFFLINE=1`). يظل الجهاز اللوحي غير متاح للاختبار، ولا يوجد UI/API إنتاجي أو تكامل مع أدوات حقيقية.

**بوابة R4 التاريخية:** سُلّم `MANAGER_HANDOFF_R4.txt` وحُفظ خط R4. فُوضت R5 لاحقًا بقرار منفصل D-032؛ هذا لا يجيز UI أو أي مرحلة تالية.


## موجز R5

أضافت R5 API تطويرية محلية، PostgreSQL/SQLAlchemy/Alembic، MongoDB Async، حفظًا منسقًا لنتائج R4 وأحداث/أدلة R2، ومصالحة idempotent عند الفشل الجزئي. أضيفت عمليات Chroma مضبوطة للسياسات مع حالات pending واستبعاد OBSOLETE من RAG ومن قواعد R3. التحليل الأمني ما زال من R3 فقط.

الاختبارات الكاملة بعد R5: **98 passed, 1 skipped**. اختبار PostgreSQL/Mongo الحي متاح فقط مع قواعد اختبار مخصصة ولم يُنفذ لغياب الخدمات. لا ادعاء بتوافق Samsung Galaxy Tab S7+ / Debian PRoot. مواصفات التنفيذ والتشغيل في `docs/R5_BACKEND_SPEC.md` و`docs/R5_LOCAL_DATABASE_SETUP.md`.

**بوابة R5:** سلّم `MANAGER_HANDOFF_R5.txt` وانتظر اعتماد المدير. لا تدمج إلى `main`، ولا تبدأ R6–R11 أو Dashboard/UI أو T1–T3 دون تفويض منفصل.
